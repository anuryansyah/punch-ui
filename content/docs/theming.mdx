# Sistem Desain & Theming

Seluruh komponen dikendalikan melalui CSS Variables di `src/styles/globals.css` dan `src/styles/themes.css`:

- `[data-theme="tangerine"]` — Default Orange (Tangerine Punch)
- `[data-theme="soft-blue"]` — Soft Blue
- `[data-theme="cyber-yellow"]` — Cyber Yellow
- `[data-theme="deep-ink"]` — Deep Ink
- `[data-theme="soft-pink"]` — Soft Pink
- `[data-theme="crimson-red"]` — Crimson Red
