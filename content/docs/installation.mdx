# Instalasi

Komponen dapat diinstal langsung melalui CLI `shadcn` menggunakan URL Custom Registry tanpa perlu menginstal paket NPM tambahan.

```bash
npx shadcn@latest add https://punch-ui.vercel.app/r/button.json
```
