# Punch UI

**Punch UI** adalah koleksi komponen berbasis **shadcn/ui (Radix UI)** dan **Tailwind CSS** yang dirancang dengan estetika Neobrutalism modern:

- **Border Tegas:** Garis tepi hitam pekat (`2px solid #000000`).
- **Hard Shadow Responsif:** Bayangan solid tanpa blur (`shadow-brutal-sm md:shadow-brutal`).
- **Interaksi Mekanis:** Tombol dan elemen interaktif menekan ke arah bayangan saat diklik.
- **6 Preset Tema Warna:** **Tangerine Punch**, **Soft Blue**, **Cyber Yellow**, **Deep Ink**, **Soft Pink**, dan **Crimson Red**.
